# Contributing

Open an issue describing the reproducible problem before a substantial change. Use Python 3.11 and run `python -m pytest -q` and `python -m compileall -q src HIERA_VEP_COMPLETE_CODE.py` before a pull request.

Preserve the locked model, feature order, scaling specification, and reported results. Any new scientific analysis must be clearly distinguished from the locked release. Include provenance and tests for inference changes. Do not submit raw datasets, credentials, personal information, or pretrained foundation-model weights.
